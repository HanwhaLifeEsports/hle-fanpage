# OBS 설정 — 관전 화면 + 오버레이 → 유튜브

맥에서 롤 관전 창을 캡처하고, 그 위에 `overlay.html` 을 얹어 유튜브로 내보내는 설정입니다.
한 번만 만들어 두면 다음부터는 **송출 시작** 버튼 하나입니다.

---

## 0. 먼저 — 맥 권한 두 개

OBS 를 처음 켜면 이것부터 막힙니다. **시스템 설정 → 개인정보 보호 및 보안** 에서:

| 항목 | 왜 필요한가 |
|---|---|
| **화면 기록** | 게임 창을 캡처하려면 필수. 없으면 소스가 까맣게 나옵니다 |
| **손쉬운 사용** | (선택) 창 자동 포커스 등 자동화를 붙일 때 |

권한을 준 뒤 **OBS 를 완전히 종료했다 다시 켜야** 적용됩니다.

---

## 1. 프로필 · 장면 만들기

**프로필 → 새로 만들기** → `솔랭관전`
**장면 모음 → 새로 만들기** → `솔랭관전`

이렇게 나눠두면 다른 방송 설정과 섞이지 않습니다.

### 출력 해상도

**설정 → 비디오**

| 항목 | 값 |
|---|---|
| 기본(캔버스) 해상도 | `1920 x 1080` |
| 출력(조정된) 해상도 | `1920 x 1080` |
| 축소 필터 | 랜초스 |
| FPS | `60` (약하면 `30`) |

> 오버레이가 1920×1080 기준으로 그려져 있습니다. 캔버스를 다른 값으로 두면 브라우저 소스
> 크기와 어긋나므로, 캔버스는 1920×1080 으로 두고 필요하면 출력만 낮추세요.

---

## 2. 장면에 소스 3개

### ① 게임 화면 (맨 아래)

**소스 + → 윈도우 캡처**

| 항목 | 값 |
|---|---|
| 윈도우 | `League of Legends (TM) Client` |
| 윈도우 매칭 우선순위 | **실행 파일 이름 매칭** |
| 커서 표시 | 끄기 |

> **"실행 파일 이름 매칭"** 이 중요합니다. 관전 창은 매번 새로 뜨는데, 기본값(제목 매칭)이면
> 창이 바뀔 때마다 소스를 다시 골라야 합니다.

관전 창이 안 떠 있으면 목록에 안 보입니다. 관전을 한 번 띄운 상태에서 만드세요.

### ② 오버레이 (게임 위)

**소스 + → 브라우저**

| 항목 | 값 |
|---|---|
| URL | `http://127.0.0.1:3200/overlay.html` |
| 너비 / 높이 | `1920` / `1080` |
| 사용자 지정 CSS | **비우기** |
| 장면이 활성화되지 않으면 소스 종료 | 끄기 |
| 장면이 활성화되면 브라우저 새로 고침 | 켜기 |

> **사용자 지정 CSS 를 반드시 비우세요.** OBS 는 기본으로
> `body { background-color: rgba(0,0,0,0); margin: 0; overflow: hidden; }` 를 넣어두는데,
> 이건 그대로 둬도 됩니다. 다만 배경색을 칠하는 CSS 를 넣으면 게임이 가려집니다.

`node overlay/proxy.mjs` 가 떠 있어야 합니다. 안 떠 있으면 소스가 빈 화면입니다.

### ③ (선택) 마이크 / 배경음

해설을 얹을 거면 **오디오 입력 캡처**. 아니면 생략하세요.

> 게임 소리를 넣으려면 맥에서는 가상 오디오 장치(BlackHole 등)가 따로 필요합니다.
> macOS 는 앱 소리를 직접 캡처하지 못합니다.

## 3. 순서와 크기

소스 목록은 **위에 있는 것이 앞에** 그려집니다.

```
브라우저 (오버레이)     ← 위
윈도우 캡처 (게임)      ← 아래
```

게임 캡처를 선택하고 **우클릭 → 변환 → 화면에 맞추기**(⌘F).
관전 창이 1600×900 이면 1920×1080 캔버스에 맞게 늘어납니다.

> 관전 창 해상도는 `LoL/Game/Config/game.cfg` 의 `Width`/`Height` 로 정합니다.
> `WindowMode` 는 **`1` 이 창모드**입니다 (`0` = 전체화면 — 모니터 해상도가 바뀝니다, `2` = 테두리없음).
> 바꾼 뒤에는 관전 창을 새로 띄워야 적용됩니다.

---

## 4. 관전 클라이언트의 기본 UI 끄기

**이걸 안 하면 인게임 스코어보드와 이 오버레이가 겹칩니다.**

관전 창에서 **`U`** 키 — 인터페이스 전체를 껐다 켭니다.
부분만 끄려면 `설정 → 인터페이스` 에서 개별 요소를 조정하세요.

권장:
- 인게임 상단 스코어바 — 끄기 (오버레이 상단 띠와 겹침)
- 우측 스코어보드 — 끄기 (오버레이 레일과 겹침)
- 미니맵 — **켜두기** (오버레이에 미니맵이 없습니다. 관전 API 에 좌표가 없어서 못 만듭니다)
- 챔피언 체력바 — 켜두기 (오버레이에 체력이 없습니다)

## 5. 유튜브 송출

**설정 → 방송**

| 항목 | 값 |
|---|---|
| 서비스 | YouTube - RTMPS |
| 서버 | Primary YouTube ingest server |
| 계정 연결 | **계정 연결(권장)** 을 눌러 로그인 |

계정을 연결하면 OBS 안에서 방송 제목·공개범위를 정하고 바로 시작할 수 있습니다.
스트림 키를 직접 붙여넣는 방식도 되지만, 연결 방식이 방송 관리까지 되어 편합니다.

**설정 → 출력** (고급 모드)

| 항목 | 값 |
|---|---|
| 인코더 | **Apple VT H264 하드웨어 인코더** |
| 비트레이트 | `6000 Kbps` (1080p60), `4500` (1080p30) |
| 키프레임 간격 | `2` 초 |
| 프로파일 | high |

> 맥에서는 x264(소프트웨어) 대신 **Apple VT 하드웨어 인코더**를 쓰세요. CPU 를 훨씬 덜 먹고,
> 관전 클라이언트와 같이 돌릴 때 프레임이 안 떨어집니다.

### 팬페이지에 붙이기

유튜브 채널 ID(`UC…`)를 `.env.local` 의 `NEXT_PUBLIC_SOLOQ_YT_CHANNEL` 에 넣으면
`/soloq` 페이지가 그 채널의 현재 라이브를 자동으로 임베드합니다. 방송마다 URL 을 바꿀 필요가 없습니다.

---

## 6. 실제 진행 순서

```bash
# 1. 오버레이 서버
node overlay/proxy.mjs

# 2. 관전 띄우기 (실패하면 자동 재시도)
node overlay/spectate.mjs --scan 90 --retry 4
```

3. 관전 창이 뜨면 **`U`** 로 인게임 UI 끄기
4. OBS 에서 게임 캡처 소스가 잡혔는지 확인
5. **송출 시작**

관전 창은 경기가 끝나면 스스로 닫힙니다. 다음 경기를 보려면 2번을 다시 실행하고,
OBS 는 켜둔 채로 두면 됩니다 (윈도우 캡처가 실행 파일 매칭이면 새 창을 알아서 다시 잡습니다).

## 자주 겪는 문제

| 증상 | 원인 · 해결 |
|---|---|
| 게임 캡처가 까맣다 | 화면 기록 권한 없음 → 권한 주고 OBS 재시작 |
| 오버레이가 빈 화면 | `proxy.mjs` 가 안 떠 있음 |
| 오버레이에 "관전 대기 중" 만 | 관전 창은 떴는데 스트림을 못 받는 중. `spectate.mjs` 가 재시도합니다 |
| 오버레이 배경이 검다 | 브라우저 소스의 사용자 지정 CSS 에 배경색이 들어감 |
| 스코어보드가 두 겹 | 관전 창에서 `U` 를 안 눌렀음 |
| 관전 창이 2분 만에 닫힘 | op.gg 프록시 청크 실패(실측 성공률 약 40%). `--retry` 를 늘리세요 |
| 모니터 해상도가 바뀜 | `game.cfg` 의 `WindowMode` 가 `0`(전체화면). `1`(창모드)로 고치세요 |
