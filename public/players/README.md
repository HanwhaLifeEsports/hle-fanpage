# 공식 선수 사진

2026-10-01 사용자 요청에 따라 한화생명e스포츠 공식 홈페이지(https://hle.kr/)의 주전 5명 프로필 사진을 등록했습니다.

원본 URL, 선수별 파일 경로, 크기와 확인일은 `sources.json`에 기록했습니다. 원본 이미지 바이트를 그대로 보관하며 실제 파일 형식은 JPEG입니다.

`basis: official`은 공식 홈페이지에 게시된 사진이라는 출처 분류입니다. 별도 사용 허락을 받았다는 의미의 `permission`과 구분합니다. 카드 갤러리에 공식 출처 링크를 표시합니다.

사진 표시를 끄려면 `NEXT_PUBLIC_PLAYER_PHOTOS=off`로 설정한 뒤 다시 빌드합니다.
