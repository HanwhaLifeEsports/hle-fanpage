# HLE FAN

한화생명e스포츠 **비공식** 팬 페이지. 2026 LCK 시즌 기준.

경기 알림 · 실시간 중계 · 커뮤니티 · 승부예측을 담은 웹앱(PWA 지향)입니다.

> 이 저장소는 팬이 운영하는 비공식 프로젝트이며, 구단·라이엇게임즈와 무관합니다.

---

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
```

## 라이브 중계 (핵심)

`GET /api/live` 가 서버에서 중계 플랫폼을 폴링해 방송 여부를 판정합니다.
클라이언트는 30초마다 이 엔드포인트를 호출합니다.

### 왜 서버가 필요한가

치지직·SOOP API 모두 브라우저 `Origin` 헤더가 붙으면 **403(CORS 차단)** 을 돌려줍니다.
정적 페이지에서는 라이브 여부를 알 수 없어 Route Handler 로 프록시합니다.

### 플랫폼별 실측 결과

| 플랫폼 | 라이브 판정 | 페이지 내 재생 | 비고 |
|---|:---:|:---:|---|
| **치지직** | ✅ | ❌ | `/embed/clip/{id}` 만 지원. 라이브 임베드 라우트 없음 → 딥링크 |
| **SOOP** | ✅ | ✅ | 공식 임베드. 방송 중일 때 `broad_no` 를 받아 해당 방송으로 연결 |
| **YouTube** | ❌ | 국제 대회만 | 판정엔 Data API 키 필요. `live_stream` 임베드가 스스로 라이브를 해석 |
| **Disney+** | ❌ | ❌ | DRM(Widevine) + 로그인 필수 → 딥링크만 |

### 대회별 송출 채널

`broadcastsFor()` 가 대회 종류에서 파생시킵니다 (하드코딩 아님).

- **LCK 정규시즌** — 치지직 · SOOP 동시 생중계 / 유튜브는 하이라이트·다시보기
- **국제 대회** (First Stand · MSI · Worlds) — 치지직 · SOOP · 유튜브 생중계
- **비시즌 컵** (KeSPA CUP 등) — Disney+

> 2026~2030 LCK 국내 중계권은 네이버(치지직)·SOOP 독점입니다.
> 유튜브는 2026년부터 국내 정규시즌 생중계를 하지 않습니다.

## 데이터: 실제 vs 샘플

| 실제 확인분 | 샘플 |
|---|---|
| 2026 HLE 로스터 · 코칭스태프 | 경기 일정 / 전적 |
| LCK 10개 팀 명칭·태그 | 순위표 승패·세트득실 |
| 시즌 포맷 (정규 4R, 레전드/라이즈 그룹, PO 진출 방식) | 선수 개인 스탯 (KDA·DPM) |
| 시즌 일정 (2026-04-01 개막 ~ 09-13 결승) | 커뮤니티 글·예측 랭킹 |
| 중계권 구조 및 채널 ID | |

실서비스에서는 수집기(Leaguepedia 등) + 관리자 오버라이드 2중 구조로 채울 것.
자동 수집이 깨져도 서비스가 멈추지 않아야 합니다.

## 디자인 시스템

`getdesign` 의 **nike** 를 뼈대로 **playstation** 의 카드·챕터 전환을 이식했습니다.

- 캔버스는 다크(`#08090A`) — 팬이 이 사이트를 여는 시각이 대부분 경기 시간대이기 때문
- 오렌지(`#FF6A13`)는 장식이 아닌 **신호** — 주 CTA · LIVE · 활성 탭 · 최애 뱃지에만. 화면당 1~2회
- 승리는 LoL VICTORY 화면의 바이올렛(`#A98CFF`) — 오렌지의 보색이라 검은 캔버스에서 둘 다 선명
- 드롭섀도 0. 깊이는 1px 헤어라인으로만
- 서체: 한글·라틴 UI 는 **Freesentation**, 라틴 초대형 디스플레이는 **Anton**

## 스택

Next.js 16 (App Router) · React 19 · TypeScript · 순수 CSS(디자인 토큰)

상태는 `localStorage` 기반 클라이언트 스토어(`src/lib/useDemoState.ts`)입니다.
인증·DB·실제 웹푸시 발송은 아직 없습니다.

## 개발용 스위치

방송이 없는 시간대에도 라이브 UI 를 보려면 **MY → 개발용 → 강제 LIVE** 를 켜세요.
(`/api/live?force=1`) 실제 송출이 없으면 플레이어 자리에 자리표시자가 뜹니다.
