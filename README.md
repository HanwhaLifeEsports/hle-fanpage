# HLE FAN

한화생명e스포츠 **비공식** 팬 페이지. 2026 LCK 시즌 기준.

경기 알림 · 실시간 중계 · 커뮤니티 · 승부예측을 담은 웹앱(PWA 지향)입니다.

> 이 저장소는 팬이 운영하는 비공식 프로젝트이며, 구단·라이엇게임즈와 무관합니다.

npm run dev     # http://localhost:3000

## 순위 · 일정 (LoL Esports API)

`getStandingsV3` · `getSchedule` 를 서버에서 모아 5분 캐시한다 (`src/lib/season.ts`).
CORS 가 `*` 로 열려 있어 브라우저 직접 호출도 되지만, 아래 가공이 무거워서 서버에 둔다.

### 왜 그냥 못 쓰는가

1. **스플릿이 분리돼 있다.** 2026 시즌은 `lck_split_2_2026`(정규 1~2R)과
   `lck_split_3_2026`(3~4R 그룹)이 별개 토너먼트다. 실제 정규 순위는 **두 스플릿의 합산**이라
   API 한 곳만 보면 순위가 완전히 뒤집힌다.
   (예: 스플릿3만 보면 HLE 1승 3패 최하위 → 합산하면 16승 6패 2위)
2. **세트 득실을 주지 않는다.** `getStandingsV3` 의 `columns`·`scores` 가 빈 배열이다.
   `getSchedule` 의 `match.teams[].result.gameWins` 로 직접 집계한다.
3. **정규 경기만 골라야 한다.** `blockName` 이 `"N주 차"` 인 것만 순위에 반영된다.
   플레이-인 · 플레이오프 · 결승 · 토너먼트 스테이지는 제외.
4. **일정은 커서 페이징이다.** `pages.older` 를 따라가야 시즌 전체가 나온다 (2페이지면 충분).

동률은 LCK 방식대로 **승-패 → 승자승 → 세트 득실** 순으로 가른다.

## 플레이오프 경우의 수

`src/lib/scenarios.ts` — 그룹의 남은 경기를 **세트 스코어까지** 전수 전개한다.
BO3 한 경기는 2-0 / 2-1 / 1-2 / 0-2 네 가지이므로 `4^n`. 승패만 보는 `2^n` 으로는
세트 득실 동률이 갈리지 않는다.

산출물: 최종 순위 확률 분포 · 잔여 승수별 진출 확률과 최선/최악 순위 ·
경기별 영향력(승패에 따른 확률 진폭). 잔여 10경기 기준 약 105만 가지를 0.7초에 계산한다.

## 라이브 중계 (핵심)

`GET /api/live` 가 서버에서 중계 플랫폼을 폴링해 방송 여부를 판정합니다.
클라이언트는 30초마다 이 엔드포인트를 호출합니다.

### 왜 서버가 필요한가

치지직·SOOP API 모두 브라우저 `Origin` 헤더가 붙으면 **403(CORS 차단)** 을 돌려줍니다.
정적 페이지에서는 라이브 여부를 알 수 없어 Route Handler 로 프록시합니다.

### 플랫폼별 실측 결과

| 플랫폼 | 라이브 판정 | 페이지 내 재생 | 비고 |
|---|:---:|:---:|---|
| **치지직** | ✅ | ✅ | iframe 임베드는 없지만 HLS 를 직접 재생한다 (아래) |
| **SOOP** | ✅ | ✅ | 공식 임베드. 방송 중일 때 `broad_no` 를 받아 해당 방송으로 연결 |
| **YouTube** | ❌ | 국제 대회만 | 판정엔 Data API 키 필요. `live_stream` 임베드가 스스로 라이브를 해석 |
| **Disney+** | ❌ | ❌ | DRM(Widevine) + 로그인 필수 → 딥링크만 |

### 치지직 자체 플레이어

치지직에는 라이브용 iframe 임베드 라우트가 없다(클립만 있다). 대신 재생 정보가 공개돼 있어
`<video>` + hls.js 로 직접 재생한다. 실측으로 확인한 조건:

| 항목 | 결과 |
|---|---|
| `playbackAuthType` | `NONE` — 인증 토큰 불필요 |
| DRM | 없음 |
| CORS | 마스터 m3u8 · 청크리스트 · 세그먼트 전 구간에서 요청 Origin 허용 |

`/api/chzzk/stream` 이 `live-detail` 에서 `livePlaybackJson.media[HLS].path` 를 꺼내 넘기고
(이 API 자체는 CORS 가 막혀 서버 경유가 필요하다), 클라이언트가 hls.js 로 붙는다.
hls.js 는 플레이어가 실제로 열릴 때만 동적으로 불러온다.

> 크로미움은 `canPlayType('application/vnd.apple.mpegurl')` 에 `"maybe"` 를 돌려주면서도
> HLS 를 디먹싱하지 못한다. 그래서 hls.js 를 먼저 시도하고 MSE 가 없는 iOS 사파리에서만
> 네이티브로 떨어진다.

**끄는 법**: `NEXT_PUBLIC_CHZZK_PLAYER=off` 를 넣으면 딥링크만 남는다.
공식 플레이어를 거치지 않으므로 광고·시청자수 집계가 빠진다는 점은 알고 쓸 것.

### 대회별 송출 채널

`broadcastsFor()` 가 대회 종류에서 파생시킵니다 (하드코딩 아님).

- **LCK 정규시즌** — 치지직 · SOOP 동시 생중계 / 유튜브는 하이라이트·다시보기
- **국제 대회** (First Stand · MSI · Worlds) — 치지직 · SOOP · 유튜브 생중계
- **비시즌 컵** (KeSPA CUP 등) — Disney+

> 2026~2030 LCK 국내 중계권은 네이버(치지직)·SOOP 독점입니다.
> 유튜브는 2026년부터 국내 정규시즌 생중계를 하지 않습니다.

## 배포

Vercel 에 그대로 올라간다. 환경변수는 선택 사항이다 (`.env.example` 참고).
`NEXT_PUBLIC_SITE_URL` 을 넣으면 OG·사이트맵 절대경로가 그 도메인으로 잡힌다.

### 팬 사진 (Supabase)

선수 프로필에서 팬이 직접 찍은 사진을 4:5 로 잘라 올리고, 하트가 가장 많은 사진이
선수 카드에 걸린다. 저장소는 Supabase 다.

- 권한은 코드가 아니라 **RLS** 에 있다 (`supabase/schema.sql`). anon 키가 공개되는
  값이라 브라우저를 믿는 방식은 애초에 성립하지 않는다. 하트 중복은 `(사진, 익명 id)`
  기본키가, 도배는 업로드 정책의 10분 5장 조건이 막는다.
- 신고 한 건이면 **즉시** 가린다. 저작권법 제102조 제1항이 침해를 알게 된 때 즉시
  중단시킨 경우에 책임을 제한하기 때문이다. 근거 없는 신고는 운영자가 되돌린다.
- 열쇠가 없으면 브라우저(IndexedDB)로 떨어진다. 화면은 같지만 하트가 그 기기에서만
  세어져서 "하트 1위" 가 성립하지 않고, 갤러리 아래에 그 사실을 그대로 적는다.
- 붙이는 순서는 `.env.example` 에 있다.

### 아직 서버가 필요한 것

원격 푸시 **발송**은 VAPID 키 + 구독 저장소 + 스케줄러가 있어야 한다. 지금은
서비스워커와 알림 권한까지만 준비되어 있고, 앱이 열려 있는 동안의 알림만 실제로 뜬다.
커뮤니티도 로그인·DB·신고 처리가 갖춰져야 열 수 있어 준비 중 화면으로 두었다.
